## 📁 Proyectos

### 🔹 01 - Control de Finanzas con Python y SQLite
* **Descripción:** Aplicación en consola para registrar ingresos/gastos y consultar el historial financiero persistido en una base de datos relacional.
* **Tecnologías usadas:** Python, SQLite, SQL (DDL & DML).
* **Conceptos clave:** Conexión a bases de datos, consultas `SELECT`, inserción `INSERT`, creación de tablas condicionales (`IF NOT EXISTS`).
